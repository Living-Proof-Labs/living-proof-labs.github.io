# Guides by role

Start from what you are trying to do. Each guide is owned and published by its
project; this page only points you to the right one.

| I want to… | Start with | You will find |
| --- | --- | --- |
| Try the demo end to end | [Quickstart](quickstart.md) | Clone, `task demo` and a rendered report |
| Write or review a capability specification | [Robot capability specifications](https://docs.livingprooflabs.com/robot-capability-specs/) | Requirements, conditions and acceptance criteria |
| Run verification and collect evidence | [Capability verifier](https://docs.livingprooflabs.com/capability-verifier/) | Fixture execution and portable evidence |
| Grade results and read reports | [Capability reporter](https://docs.livingprooflabs.com/livingproof-capability-report/) | Bundle validation, policy grading and reports |
| Use the command line and plugins | [LivingProof](https://docs.livingprooflabs.com/livingproof/) | Command entry point and installed plugins |
| Simulate | [MuJoCo simulator](https://docs.livingprooflabs.com/livingproof-sim-mujoco/) | A standalone native engine example; not yet connected to the capability pipeline |
| Build on shared code | [Common library](https://docs.livingprooflabs.com/livingproof-common/) | Shared library interfaces |
| Contribute to any project | [Collaboration guidelines](https://docs.livingprooflabs.com/collaboration-guidelines/) | Shared contribution and engineering standards |

The full list of projects, including repositories without a hosted manual, is in
the [project reference](index.html#published-manuals).
