# Living Proof Labs documentation

Find a manual, explore a project, or learn how to contribute.
Read our [vision, terminology, and current scope](vision.html): connecting
software and capability requirements to evidence, policy grades, reports, and
a developer feedback loop. Fixtures demonstrate that loop today; hardware and
capability-pipeline simulation remain future work.

<a id="livingproof"></a>

## Published manuals

Each manual is independently published. Its documentation source revision may
be newer than its package release; check Version and source before installation.

| Rendered manual | Scope |
| --- | --- |
| [LivingProof](https://docs.livingprooflabs.com/livingproof/) | Command entry point and installed plugins |
| [Capability reporter](https://docs.livingprooflabs.com/livingproof-capability-report/) | Bundle validation, policy grading and reports |
| [Capability verifier](https://docs.livingprooflabs.com/capability-verifier/) | Fixture execution and portable evidence |
| [Robot capability specifications](https://docs.livingprooflabs.com/robot-capability-specs/) | Requirements, conditions and acceptance criteria |

## Version and source

This directory follows the current default branch; historical rendered copies are
not maintained. Use source history for earlier revisions. Documentation identity
is separate from each project's package or catalog release.

Contributors follow [guidelines v6.0.0](https://github.com/Living-Proof-Labs/collaboration-guidelines/tree/v6.0.0)
and this repository's editorial validation instructions. See
[license scopes](https://github.com/Living-Proof-Labs/living-proof-labs.github.io/blob/main/LICENSE.md). No private security reporting route is documented here.
